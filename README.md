# code-ninja0208 Portfolio

Personal portfolio for **Data Engineering • AI & Data Systems • Full-Stack Engineering • Web3 Development**.

## Stack

- **Data:** Python, SQL, PostgreSQL, MySQL, MongoDB
- **AI / Backend:** FastAPI, Django, Node.js, Express, NestJS
- **Frontend:** React, Next.js, Vue, Angular, TypeScript
- **Web3:** Solidity, Rust, JavaScript, TypeScript
- **Cloud / DevOps:** AWS, Docker, Kubernetes, Vercel
- **Data access:** Prisma, GraphQL

## GitHub synchronization

The portfolio uses the public GitHub API for **code-ninja0208** to populate the latest repository cards automatically. Repository data is cached for 15 minutes and refreshed in the background, so newly created or updated public repositories can appear without editing portfolio content.

## Development

```bash
yarn install
yarn dev
```

Create `.env.local` only for optional private integrations used by the original application. The GitHub project sync does not require a personal access token because it reads public repository metadata.
